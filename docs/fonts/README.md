# الخطوط

ملفات خط **Haradh** (© Saudi Aramco) غير مضمّنة في المستودع لأن رخصة إعادة توزيعها غير معلنة.
للبناء المحلي بالخط نفسه ضع الملفات هنا:

- haradh-regular.otf
- haradh-semibold.otf
- haradh-bold.otf
- haradh-heavy.otf

عند غيابها تعود صفحة الويب تلقائيًا إلى خط **Noto Naskh Arabic** من Google Fonts، والـ PDF إلى Noto Naskh Arabic المثبّت على النظام.
